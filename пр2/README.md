# Практическая работа № 2 — адаптивный каталог

## Запуск

Распакуйте весь архив и откройте `index.html` в современном браузере. CSS, товары и иллюстрации лежат рядом в проекте, поэтому для просмотра не нужны сервер или установка пакетов. Фильтры работают на JavaScript в браузере.

## Структура

- `index.html` — шапка, фильтры, область каталога, блок о проекте и подвал.
- `js/catalog.js` — 18 записей из CSV, построение карточек, поиск, фильтрация по категории и максимальной цене, сортировка и пустое состояние.
- `scss/styles.scss` — точка входа SCSS.
- `scss/_variables.scss` — тема из `data/theme.json`: основные цвета, радиус и интервал; также ширина контейнера.
- `scss/_mixins.scss` — переиспользуемые правила контейнера и клавиатурного фокуса.
- `scss/_base.scss`, `scss/_layout.scss`, `scss/_components.scss` — базовые стили, раскладка и компоненты.
- `css/styles.css` — готовый CSS, подключённый страницей.
- `data/catalog.csv`, `data/theme.json` — оригинальные входные данные.
- `images/product-01.svg` — иллюстрация категории «Книги»; `product-02.svg` — «Курсы»; `product-03.svg` — «Инструменты».

## Данные и интерфейс

В каталоге показаны все 18 строк `catalog.csv`. Названия, категории, цены и оценки перенесены без изменений в массив `products` в `js/catalog.js`. Фильтры меняют видимый набор карточек; сообщение о пустом результате отображается, если совпадений нет. Значения цветов, основного фона, радиуса и интервала берутся из `theme.json` и собраны в SCSS-переменных в одном месте.

## SCSS и компиляция

В SCSS используется модульная структура `variables`, `mixins`, `base`, `layout`, `components`. Вложенность ограничена короткими селекторами; `@mixin container` и `@mixin focus-ring` устраняют повторение; функция `space($factor)` вычисляет кратные интервалы из базового значения.

Установите Sass один раз:

```sh
npm install
```

Одноразовая сборка:

```sh
npm run build:css
```

Сборка при каждом изменении SCSS:

```sh
npm run watch:css
```

Готовый `css/styles.css` уже приложен, так что каталог можно открыть и без этих команд. После изменения SCSS запустите сборку, чтобы обновить CSS.

Переменная SCSS `$accent` вычисляется компилятором и не остаётся переменной в CSS. CSS custom property вроде `--accent` существует в браузере и может меняться во время выполнения через каскад или JavaScript. В этом проекте SCSS-переменные хранят исходную тему, а CSS custom properties дают собранным стилям единые значения оформления.

## Контрольная проверка

На широкой странице фильтры стоят слева, карточки располагаются в три колонки; при сужении карточки перестраиваются в две, затем в одну колонку, а панель фильтров переходит над каталогом. Проверьте ширины 375, 768 и 1440 px, поиск без совпадений, сброс фильтров и все изображения. Область должна оставаться без горизонтальной прокрутки.

## Ответы на контрольные вопросы

1. Входные данные — строки `data/catalog.csv`, тема `data/theme.json` и три SVG в `images/`.
2. `js/catalog.js` хранит перенесённые записи, фильтрует их и строит карточки в `#productGrid`. Это клиентский маршрут данных; CSV сохраняется рядом как исходный источник.
3. Проверяется пустое состояние каталога, когда поиск или фильтры не находят товары. Кнопка «Сбросить» восстанавливает исходный список.
4. При росте каталога данные следует загружать автоматически из CSV/JSON, вынести карточку в компонент, добавить проверку данных и отдельные модули фильтрации.
5. После чистого клонирования достаточно открыть `index.html`; для разработки стилей выполнить `npm install`, `npm run build:css`.
6. HTML задаёт смысл и структуру, CSS задаёт оформление и расположение. Каталог остаётся структурированным и читаемым независимо от декоративных правил.
7. Работа использует собственный небольшой JavaScript для фильтров. Bootstrap JavaScript не подключён и для этой работы не нужен.
